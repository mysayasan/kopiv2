# 术语表

这些术语按本产品的用法解释。有些词在别处用得比较宽泛；这里给出的是在这些界面上适用的含义。

**保留期**——录像在被自动清理前保留的天数。按摄像机设置。参见
[录像配置](recording-configuration#retention)。

**冷却时间**——规则触发后保持安静的时长，让一件持续发生的事只产生一条告警。

**帧率码流（检测码流）**——AI 读取的那一路摄像机码流。通常是子码流，且与录像码流相互独立。参见
[码流标签页](camera-properties#stream)。

**告警**——规则触发时产生的东西：时间戳、摄像机、看到了什么、一张截图，以及有录像时指向录像的链接。

**观看者**——权限最小的角色：实时视频，以及"告警发生过"这一事实，仅此而已。

**规则**——某台摄像机上的常设指令：模式、类别、区域、时段、阈值和路由。参见
[创建检测规则](detection-rules)。

**技能**——通过[教学模式](teach-mode)教会摄像机识别的东西。

**截图**——规则触发那一刻捕获的静态图像，检测结果已框出并标注。

**码率**——一路码流每秒产生多少数据。它是保留期消耗多少磁盘的主要驱动因素。

**密码学擦除**——销毁加密密钥使密文再也无法读取，而不是覆写数据。这正是恢复出厂在 SSD 上得以有保证的
原因。

**目击**——对象时间线中的一条记录：看到一个对象，跨帧归并而不是逐帧记录。参见
[对象检索](object-search#sightings)。

**外观检索**——按与您所选目击的相似程度而非对象类别对已记录目击排序。是供您用肉眼核实的候选名单，
不是身份鉴定。参见[找相似](object-search#appearance)。

**内置模型（基础模型）**——始终开启、识别常见日常类别的基础检测模型。与任何自定义模型并行运行。参见
[模型](how-detection-works#models)。

**诊断事件**——为向您展示检测器看到了什么而记录的样本，带有标记以便与真实检测分开清理。

**节点**——由 myseliasan 控制平面管理的一台设备。

**类别**（对象类别）——您定义的名称，映射到一个或多个模型标签。*车辆* = `car`、`truck`、`bus`。规则是
针对它写的。参见[对象类别](object-classes)。

**前录**——事件片段中保留的触发*之前*的秒数。通常正是您需要的部分。

**人脸特征**——已录入人员面部的数学表示。属于生物识别数据，附带法律义务。参见[人员](people#consent)。

**认领码**——纳管节点时在控制平面中输入的短期代码。参见[连接到控制平面](control-plane#claim-code)。

**恢复出厂**——粉碎所有数据、销毁密钥、重建数据库并重启进入首次配置。参见
[安全擦除与恢复出厂](secure-wipe-and-reset)。

**LPR**——车牌识别。读取车牌文字，并在可用时读取车辆类型和颜色。参见
[火焰、烟雾与车牌](fire-smoke-and-plates#lpr)。

**MJPEG**——一种回退投递方式，设备把视频转成静态图片给浏览器。哪里都能用，但 CPU 开销远高于 WebRTC。

**ONVIF**——发现和管理 IP 摄像机的行业标准。可选：仅支持 RTSP 的摄像机同样可用。

**RTSP**——摄像机推送视频所用的协议。

**WebRTC**——高效的实时画面路径，浏览器直接解码摄像机自己的码流。在画面格上显示为**实时**。

**操作员**——中间角色：回看录像、确认、云台、喊话。不能删除。参见
[用户与角色](users-and-roles#roles)。

**事件片段**——围绕触发点提取的画面，包含前录和后录。

**首码流（主码流）**——摄像机的全分辨率码流。您用来录像的那一路。

**子码流**——摄像机分辨率较低的次码流。实时画面和检测通常应该用它。

**分段**——连续录像中固定长度的一块。分段越短，崩溃时损失越少。

**阈值**——规则可接受的最低置信度。

**置信度**——模型对一次检测的确定程度，0 到 1。规则的阈值是它接受的下限。

**最少帧数**——对象必须连续出现在多少帧中，规则才会触发。对付闪烁最有效的控件。

**机群密钥**——让节点能被某个 myseliasan 控制平面发现并纳管的共享秘密。参见
[连接到控制平面](control-plane#fleet-key)。

**标签**——模型为它识别出的东西输出的精确词：`person`、`car`、`fire hydrant`。精确匹配；被归入类别。

**越线**——一种规则模式，当某物越过所划的线时触发，可限定单向。

**区域**——规则所关心的、在画面上划出的范围。它是*画面*中的区域，不是现实世界中的——移动摄像机就移动了
区域。参见[区域](detection-rules#zones)。

**云台（PTZ）**——水平转动、俯仰和变焦。
