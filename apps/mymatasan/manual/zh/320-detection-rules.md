# 创建检测规则

一条规则就是某台摄像机上的常设指令：*以这种模式，盯着这些东西，在这块区域内，在这些时段里，告诉我
——并告诉这些送达目标。*

规则位于摄像机的 **AI 检测**页面。一台摄像机可以有任意多条规则，而运行若干条窄规则通常好过一条宽规则。

## 模式——它怎么看 {#modes}

| 模式 | 触发条件 |
|---|---|
| **存在** | 对象出现在画面（或区域）中的任何位置。 |
| **人群 / 计数** | 单帧中区域内至少有 *N* 个人。 |
| **入侵（区域）** | 对象进入所划区域。 |
| **越线** | 对象越过所划的线，可限定单向。 |
| **多线越线** | 对象在时限内按顺序越过多条线。 |
| **车牌（LPR）** | 看到可识别的车牌——参见[火焰、烟雾与车牌](fire-smoke-and-plates#lpr)。 |

按您真正要问的问题来选。"院子里有人吗？"是存在。"有人从大门进来了吗？"是越线——而且它不会对本来就站在
那里的人触发，而那通常正是您想要的。

**多线越线**值得了解：在时限内按顺序越过两条线，表达的是穿过某个空间的行进方向，能滤掉单条线做不到的
逗留、来回踱步和路过。

## 检测——它盯什么 {#detect}

选择对象类别。保持为**任意**，则每个被检测到的对象都匹配——这是了解某台摄像机实际会产出什么的好办法，
却是运营一个站点的糟糕做法。

类别来自注册表——参见[对象类别与分组](object-classes)。标记为**模型未激活**的类别匹配不到任何东西：产
出其标签的模型没有在运行。

## 区域 {#zones}

在摄像机预览上划出规则关心的范围。一条规则可以有**多个区域**，它们以"其中任一"的方式组合。

这是产品中价值最高的调优。对着大门的摄像机几乎总会同时对着公共人行道，而没有区域的规则会对每一个从您
门前经过的行人告警。沿着大门划一圈不会让检测器变强——它让规则问对了问题。

预览会显示某个区域占画面的百分比。工具支持增删顶点、居中矩形、翻转、旋转、吸附网格和撤销。

请记住区域是*画面*中的一块区域，不是现实世界中的。摇动或重装摄像机之后，区域就覆盖到完全不同的地方了。

## 线 {#lines}

对于越线类模式，请划一条线并设置方向。绿色箭头显示朝哪个方向穿越会触发，阴影一侧标出触发侧。点击箭头
可循环切换：一个方向 → 另一个方向 → 双向。

把线放在东西*必须*经过的地方，而不是*可能*经过的地方：大门、门口、走廊的窄处。横穿开阔地的一条线只能
抓住一条路径，漏掉另外三条。

对于多线模式，请设置**线之间的最大秒数**。太短则走得慢的人永远走不完序列；太长则相隔一小时的两件无关
事件会被合成一条告警。请实地掐一下有人真的走过去要多久。

## 置信度、帧数与冷却 {#tuning}

**阈值**、**最少帧数**和**冷却秒数**——都在[检测是如何工作的](how-detection-works#confidence)中解释。

调优顺序：先把区域划对，再调最少帧数，然后是阈值，最后是冷却。多数人先去动阈值，而它是四者中最粗糙的
一个。

## 时段 {#schedule}

规则可以**始终**运行，也可以按时段：白天、夜间、工作日、周末、自定义每周模式，或某个具体日期区间。

**策略模式**这一项要读两遍：

- **仅在此时段内检测**——规则在时段内活动，时段外沉默。
- **在此时段内暂停**——规则在时段*之外*活动。

后者正是您表达"对院子告警，但早班卸货时不要"的方式。时段有自己的时区设置，因此位于与设备不同时区的站
点会按其操作员的预期运作。

## 通知路由 {#routing}

默认情况下，一条规则的告警会发往每一个已配置的送达目标。选中特定目标即可路由——"装卸区的规则发到仓库的
MQTT 主题，而不是凌晨三点发到所有人手机上"。

如果一个送达目标都没有配置，告警仍会出现在应用内信息流中；只是没有别处可去。参见
[通知送达目标](notification-destinations)。

**声音提醒**会在任何正在观看者的浏览器中播放提示音。只在少数值得马上抬头的规则上使用，别处一律不用
——一直响的提示音就是会被静音的提示音。

## 启用、停用与读取结果 {#lifecycle}

规则可以停用而不删除，这才是验证某个想法的正确方式。

规则上线之后，同一页面上的**告警日志**就是您评判它的地方：按时间、事件、置信度或状态筛选。一天的真实
告警，比任何推理都更能告诉您一个阈值该是多少。

## 一条可用的首条规则 {#first-rule}

对多数站点、多数摄像机：

1. 模式**入侵（区域）**。
2. 检测**人员**。
3. 只沿您自己的场地划一个区域——不含人行道，不含马路。
4. 默认阈值，最少帧数 **2**，冷却约 **30** 秒。
5. 时段先用**始终**。

跑一天，读告警日志，然后收窄。这个顺序胜过事先就想调对，因为您不会调对。
