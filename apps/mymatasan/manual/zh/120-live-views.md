# 实时画面

实时画面就是电视墙：您的摄像机按您安排的网格平铺。

## 布置画面墙 {#layout}

选一个网格尺寸，然后拖动画面格重新排序。如果摄像机比网格容量多，多出来的会分页而不是被丢弃——网格是
每页的容量，不是上限。

布局按人记录在本浏览器中。两台机器上的两位操作员可以各自保留适合自己工作的排布。

## 画面格状态的含义 {#tile-status}

每个画面格都会报告它是怎样被送达的，而在排查问题时这些措辞很重要：

| 指示 | 含义 |
|---|---|
| **实时** | 直连 WebRTC 视频。高效路径——浏览器在解码摄像机自己的码流。 |
| **连接中** / **重新连接…** | 正在协商，或断开后恢复。短暂出现属正常。 |
| **MJPEG** / **MJPEG 回退** | 设备正把帧转成静态图片给浏览器。哪里都能用，但每台摄像机的 CPU 开销高得多。 |
| **WebRTC 需要 H264** | 摄像机推的编码浏览器无法直接播放，于是回退了。把摄像机码流改为 H.264 即可恢复高效路径。 |
| **摄像机离线** | 当前不可达。参见[摄像机健康](camera-health)。 |
| **实时画面已停用** | 在该摄像机自己的页面上被关掉了。 |

一面全部走 MJPEG 的画面墙，对机器的压力远大于同样一面走 WebRTC 的墙。如果画面格卡顿，先看这一列，再
去责怪硬件。

## 音频 {#audio}

画面格默认静音——一间控制室里十几路未静音的摄像机是没法用的。只把您真正在听的那一路取消静音。

如果某台摄像机的音频编码浏览器无法播放，设备会转码。这会为每个正在收听的画面格消耗 CPU，因此这也是
"有意取消静音"而非"默认取消静音"的另一个理由。

## 喊话 {#talk-back}

在带扬声器的摄像机上，麦克风按钮可以通过它讲话。它需要浏览器授予麦克风权限，也需要在该摄像机的
**访问**标签页中存好正确的密码。

用哪个密码取决于摄像机，这一点常常把人绊倒：

- **标准 ONVIF 摄像机**使用已保存的摄像机凭据。无需额外操作。
- **TP-Link Tapo** 摄像机使用您的 **TP-Link 云账号密码**——就是您登录 Tapo App 用的那个——而不是摄
  像机的码流密码。
- **TP-Link VIGI** 摄像机使用摄像机管理员密码。

如果喊话被拒绝，摄像机的访问标签页里就有针对此事的检查清单。最常见的原因是上面的 Tapo 情况；第二常
见的是用 Google 或 Apple 登录的 TP-Link 账号，在您设置一个密码之前根本没有密码可用。

## 云台 {#ptz}

在支持的摄像机上，画面格会出现云台控制。操作员和管理员可用，观看者不可用。

移动摄像机会改变它上面每一条规则所看到的内容。划好的检测区域是画面中的一块区域，而不是现实世界中的
一块区域——把摄像机转个方向，区域就覆盖到别处去了。如果您永久移动了一台摄像机，请重新检查它的规则。

## 增删画面格 {#tiles}

从摄像机自己的页面或网格自身的控件把摄像机加到墙上；用画面格上的控件移除它。移除画面格只改变您的视
图——它不会停止录像、检测或告警，这些都在设备上运行，与有没有人在看无关。

## 保存的电视墙 {#walls}

值得保留的布局就是一面**电视墙**：一个名称、一个网格，以及按你排列顺序的摄像机。保存后，所有人在任何机器上都能使用它——包括下一班的操作员，而旧的“每个浏览器各自保存”方式从来做不到这一点。

用**保存电视墙**更新当前正在看的那面墙，或用**另存为新的**把当前布局以新名称保存。可以把其中一面标记为默认；屏幕打开时就显示那一面。

> [!NOTE]
> 电视墙是共享的，不是个人的。改动它会影响所有打开它的人。这是有意为之——控制室的电视墙属于公共设施，管理员必须能够修正所有人正在看的那面墙。

如果墙上的某台摄像机被删除，墙会明确告知，而不是默默地少显示一个画面。重新保存即可移除那台不存在的摄像机。

## 轮播与告警弹出 {#cycle}

墙栏上的两个数字决定了无人操作时电视墙的行为：

- **轮播（秒）**每隔几秒切换一页，使一个岗位能看到多于网格容量的摄像机。0 表示不轮播。
- **告警弹出（秒）**在某台摄像机触发告警时把它带到当前页，并保持相应秒数。0 表示从不弹出。

弹出的摄像机显示期间，轮播会**暂停**。弹出的意义就是让人看一眼，而两秒后就转走的墙恰恰走向了报警的反面。弹出的画面会加上边框，以便一眼看出墙是为哪台摄像机跳转的。

手动翻页会重新计时，因此你刚翻到的那一页不会立刻被带走。

## 第二显示器 {#second-monitor}

**第二显示器**会在单独的窗口中打开所选的电视墙，没有导航，屏幕上也没有其他内容。把它拖到另一块显示器并全屏即可。

它是一个真正的浏览器窗口，这是有意的：应用内部的面板无法被拖到另一块屏幕上。它的登录方式与其他窗口相同，显示的也是同一面墙——因此修改这面墙会同时影响两边。
