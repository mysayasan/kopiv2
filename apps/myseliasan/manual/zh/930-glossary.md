# 术语表

**「没有发生」（absence）**——[机队规则](fleet-rules#absence)中要求某件事**没有**发生的条件。这是
规则表达清白的方式：匹配到的事件会解除规则，而不是触发它。

**接管（adoption）**——用机队密钥和认领码，把一个节点纳入本控制平面的管理。参见
[接管节点](adopting-nodes)。

**审计日志**——只追加的敏感操作记录，包含被拒绝的操作。参见[审计日志](audit-log)。

**底图（basemap）**——绘制在地图之下的街道与地形，由本地 PMTiles 文件提供。它与你自己的数据相互
独立；没有它，地图依然显示节点和建筑。

**引导移交（bootstrap handoff）**——在真正的超级管理员账号可用之后，让初始超级管理员退役。

**认领码（claim code）**——在**节点上**生成的短时效代码，用以证明该节点此刻同意被接管。机队密钥说明
属于哪支机队；认领码说明*而且我同意*。

**控制通道（control channel）**——由节点**向外**拨号连到本控制平面的连接，用于管理和串流片段。正因
如此，位于 NAT 之后的节点不需要任何入站端口映射。

**控制平面（control plane）**——就是本应用：从一块屏幕管理多台设备的那个东西。它本身不录制视频。

**冷却期（cooldown）**——机队规则触发后保持安静的时长，好让一起事件只产生一条告警。

**摘要（digest）**——关于机队做了什么的周期性说明，由计算出的结论构成，并可选地由语言模型叙述。参见
[机队摘要](fleet-digest)。

**结论（finding）**——摘要中的一条计算所得的观察（节点变安静、出现激增、证书即将到期）。它由普通代码
产生，不是模型的输出。

**机队密钥（fleet key）**——让节点只对本控制平面可被发现的共享密钥。请像对待密码一样对待它。

**机队规则（fleet rule）**——跨**不同**节点关联事件的规则。参见[机队规则](fleet-rules)。

**宽限期（grace delay）**——规则在相信某件事「没有发生」之前等待的时长，以免读卡器比门磁稍晚上报就
造成误报入侵。

**节点（node）**——一台受管设备：摄像机录像机、传感器网关、门禁控制器。

**节点访问权限（node access）**——通过隧道驱动**节点本身**的权限，分为 viewer、operator 或 admin
级别。它与控制平面自己的权限矩阵是分开的。

**等待授权（pending）**——已通过身份验证但尚无角色的账号。在管理员放行之前，它只能看到等待授权页面。

**权限矩阵（permission matrix）**——每个角色针对 API 路径前缀和动词的规则。最长匹配前缀优先；没有
规则即拒绝。它同时管辖 API **和**菜单。参见[用户、角色与访问权限](users-and-roles#access)。

**点位（placement）**——钉在楼层平面图某处的一台摄像机。每台摄像机恰好只有一个。

**PMTiles**——用于离线底图的单文件地图瓦片格式。

**释放（release）**——把节点从本控制平面移除，使其可以被重新接管。与 **wipe**（抹除节点）不同。

**自行脱离（self-drop）**——节点从它自己那侧解除配对，适用于控制平面已经不在或无法访问的情形。这会
在这里留下一条需要清理的过期记录。

**Sidecar**——当语言模型运行在控制平面本机上时，由本应用启动并监管的本地推理服务器。参见
[配置语言模型](language-model#modes)。

**场地（site）**——把位于同一地点的所有东西归到一起的位置。地图和报告都可以限定到某一个场地。

**超级管理员（superadmin）**——绕过一切权限检查的角色。无论权限矩阵如何，模型安装和设置编辑器都仅限
超级管理员。

**无法识别的节点**——持有效证书、但本控制平面没有其记录的节点。参见
[管理节点](managing-nodes#unrecognized)。

**时间窗（window）**——机队规则所需的各个事件在时间上要多接近，才算作同一起事件。

**抹除（wipe）**——对节点执行的远程恢复出厂：录像、摄像机、规则、用户和设置全部清除，然后重启。无法
撤销。
