# 配置语言模型

语言模型是**可选的**。没有它，[摘要](fleet-digest)照样计算它的结论，手册照样可以搜索；失去的是可读
的叙述和[助手](ask-the-fleet)。

下面所有内容都运行在你自己的网络上。没有任何数据被发往任何云端。

## 三种模式 {#modes}

**Off**——只有摘要，没有语言模型。控制平面出厂时就是这样。

**External**——你网络中已有的、兼容 OpenAI 接口的服务器。你提供端点 URL、可选的 API key 和模型名称。
当你已经在某台硬件比控制平面更强的机器上跑推理时，用这一种。

**Sidecar**——由本应用启动、监管并负责重启的 `llama-server` 进程，只监听回环地址。当控制平面是你唯一
可用的机器时，用这一种。

**Test** 会在你保存**之前**探测你刚输入的端点，这样打错字会在你还盯着这个输入框的时候就被发现，而不
是等到下一次有人向助手提问时。

## 安装 sidecar {#install}

两个文件：**服务器二进制**和一个**模型文件**（`.gguf`）。

如果控制平面能访问互联网，就在设置页里下载这两者。默认模型大约一个 GB；进度会显示在按钮下方。

## 隔离环境下的安装 {#air-gap}

隔离的控制平面下载不了任何东西，而这正是该功能为之设计的场景。

**Import** 可以从你带进来的文件安装——服务器压缩包，或任何你已有的 `.gguf` 模型。导入刻意不做版本
锁定：它的意义就在于接受运维人员用 U 盘带进来的文件。你所安装内容的校验和会被记入安装日志和审计
记录，因此来源是被**记录**下来的，而不是被**强制**的。

也可以为控制平面彻底关闭下载功能，此时页面会说明这一点，并转而提供 Import。

## 选择模型 {#model-choice}

模型越大，答得越好，也越慢。在 CPU 上，这个取舍就是全部的决策。

默认模型足够小，能在一台普通的控制平面上运行，对摘要叙述和直白的问题来说够用。更大的模型写出的
叙述明显更干净，引用也更可靠，而且——这是实际差别——**能稳稳地保持非拉丁语言**。如果你的运维人员读
阿拉伯语或中文，而小模型一直用英语回答，那要换的是模型，而不是某个设置。

## 调优 {#tuning}

| 设置 | 它决定什么 |
|---|---|
| **Context size** | 一次能喂给模型多少内容。摘要和助手都按它来做预算。 |
| **CPU threads** | 0 表示自动，通常就是对的。 |
| **Request timeout** | 允许一次慢回答花多长时间。 |
| **Max answer length** | 以 token 为单位限制回复长度。 |
| **Loopback port** | sidecar 在此监听；它不会暴露到本机之外。 |

CPU 推理本来就慢——首个 token 花上几秒、完整的摘要叙述花上几十秒，都是正常的，不是故障。

## 模型不可用时会发生什么 {#degradation}

每条路径都是有意地降级，而不是直接失败。

- 正在启动（加载模型需要时间）——助手会说明这一点，并请你稍后重试。
- 失败或未安装——助手不可用并说明原因；摘要照常运行。
- 崩溃——sidecar 会被自动重启。**Restart sidecar** 可立即强制重启。

没有任何重要的东西在等待推理。告警、规则、信息流和摘要的结论都不依赖它计算，正是这一性质让你可以
安心把模型关着。

## 谁可以修改 {#permissions}

安装、导入，以及把控制平面指向某个端点，都是**仅限超级管理员**的，与权限矩阵无关。这些操作可能下载
好几个 GB，或者把控制平面指向任意网络地址，因此不予下放。

而阅读摘要和使用助手则是普通授权，可以分配给某个角色。
