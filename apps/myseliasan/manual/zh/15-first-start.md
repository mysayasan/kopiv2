# 首次启动时会发生什么

## 此时还没有任何配置 {#wizard}

刚安装好的控制平面没有数据库、没有缓存，也还没有决定在哪些端口上提供服务。这些设置只在启动时读取一次，
而那时 MySeliaSan 甚至还没有拿到数据库句柄——这正是它们无法在应用内部设置的原因：那时还没有应用。

因此首次启动并不会启动控制平面，而是在它自己的端口上打开一个**安装页面**并等待你。当你完成后，控制平面
会在同一个进程内、在你刚选定的端口上启动。不需要重启任何东西。

## 找到安装页面 {#finding-it}

地址会出现在三个地方，方便你按自己的运行方式找到它：

- **你的浏览器。** 在桌面安装上它会自行打开。
- **在控制台上。** 会打印一条横幅，其中包含该地址。在 Docker 中是 `docker logs`；在 Linux 上是服务日志。
- **在文件中。** `SETUP_URL.txt` 会写入数据目录，并在安装完成后删除。当控制台内容已经滚过，或者服务在
  没有可见窗口的情况下运行时，请使用它。

该页面监听 `127.0.0.1:39530`，并且**只能从本机访问**。这是有意为之：它会接收数据库凭据和第一个管理员
密码，而此时还没有任何账户可用于登录。如果你必须从另一台机器访问它，请设置 `setup.allowRemote`——地址
中随后会带上一次性令牌，你应当把那个链接当作密码来对待。

> [!NOTE]
> 如果机器上已有其他程序占用了该端口，安装会改用一个空闲端口，并在控制台上说明。请阅读横幅，不要假定
> 就是 39530。

## 它会问什么 {#answers}

五个步骤，每一步都已用安装自带的值预填：

- **数据库** — PostgreSQL、MariaDB/MySQL，或 SQLite（单个文件，无需运行服务器）。
- **缓存** — 进程内，或 Redis。只有在负载均衡器后运行多个实例时才需要 Redis。
- **Web 地址** — HTTPS 与 HTTP 端口，以及要响应的主机名。
- **管理员** — 内置账户的名称与密码。将密码留空，系统会为本次安装生成一个。
- **核对** — 你所做的全部选择集中成一份清单，在写入任何内容之前呈现。

数据库和缓存这两步各有一个**测试连接**按钮，它会建立真实连接。请使用它。在这里发现密码错误只需一次
点击；等到之后才发现，它会让控制平面无法启动。

在你选择**完成**之前，不会写入任何内容。放弃该页面会让安装保持原样。

## 完成 {#then}

完成会把你的答案写入 `config.json` 并启动控制平面。你的浏览器会自行跟随到它的新地址。

只有问过你的那些设置会被写入——文件的其余部分都保留原有取值。随后请继续阅读
[首次登录](first-sign-in#bootstrap)。

> [!NOTE]
> 环境变量仍然优先。如果环境中设置了 `DB_HOST` 或任何其他配置变量，它会覆盖你在这里输入的值。在容器中
> 这正是你想要的，在其他任何地方则是个意外。

## 再次运行安装 {#again}

安装只运行一次。之后安装会记录自己已配置完成并直接启动，设置改为在应用内的**设置**中修改——参见
[设置](settings)。

有一个例外，也正是这个页面可以被重新召回的原因：如果控制平面已经完全无法启动——数据库迁移了、Redis
密码改了——请以 `KOPIV2_SETUP=1` 启动它，安装页面便会带着预填值回来，让你修复那些阻止它启动的设置。

数据库或缓存的短暂不可达绝不会把它召回。安装只在你主动要求时出现，或者出现在确实从未配置过的安装上。
