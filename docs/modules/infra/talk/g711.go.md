# Module: infra/talk/g711.go

## Purpose

Converts G.711 A-law (PCMA) samples to µ-law (PCMU) for cameras whose ONVIF backchannel advertises PCMU while the browser always sends PCMA.

## Responsibilities

- Build a 256-entry `alawToUlawTable` lookup table at package `init()` (both codecs carry one byte per 8 kHz sample, so conversion is a table lookup).
- `alawToLinear(a byte) int16` — decodes one A-law byte to a 16-bit PCM sample per the standard ITU-T G.711 companding formula.
- `linearToUlaw(pcm int16) byte` — encodes a 16-bit PCM sample as one µ-law byte per the standard ITU-T G.711 companding formula.
- `alawToUlaw(alaw []byte) []byte` — converts a full G.711 A-law frame to µ-law using the precomputed table, returning a new slice.

## Notes

- Called from `onvif.go`'s `WritePCMA` only when the negotiated backchannel format's `MULaw` flag is set; PCMA-native backchannels skip conversion entirely.
